═══════════════════════════════════════════════════════════════════════
  SIMPLE GUIDE: Upload Mobile App Files to GitHub
═══════════════════════════════════════════════════════════════════════

STEP 1: Delete the Two Nested Folders on GitHub
────────────────────────────────────────────────────────────────────────
Go to: https://github.com/Jthebuilder123/Pocket-Track-App

Delete these two folders:
  ✗ pockettrack-mobile/
  ✗ MOBILE-APP-FOR-GITHUB/

How to delete:
  1. Click on the folder name
  2. Click the trash icon or "Delete directory"
  3. Commit the deletion


STEP 2: Download This Folder from Replit
────────────────────────────────────────────────────────────────────────
In Replit:
  1. Right-click the "mobile-app-upload" folder
  2. Select "Download"
  3. Save to your computer


STEP 3: Upload Files to GitHub ROOT (Not in a Folder!)
────────────────────────────────────────────────────────────────────────
Go to: https://github.com/Jthebuilder123/Pocket-Track-App

You should now see an empty repo (or just a README).

  1. Click "Add file" → "Upload files"
  
  2. Open the downloaded "mobile-app-upload" folder on your computer
  
  3. SELECT ALL FILES INSIDE (not the folder itself):
     ✓ App.js
     ✓ package.json
     ✓ app.json
     ✓ eas.json
     ✓ README.md
     ✓ GITHUB-SETUP.md
     ✓ assets/ (the folder)
  
  4. DRAG these files directly onto the GitHub upload area
  
  5. Commit with message: "Add mobile app files to root"


STEP 4: Verify Your GitHub Structure
────────────────────────────────────────────────────────────────────────
Your repo should now look like this:

Pocket-Track-App/               ← Root of repository
├── App.js                      ← At root level!
├── package.json                ← At root level!
├── app.json                    ← At root level!
├── eas.json                    ← At root level!
├── README.md                   
├── GITHUB-SETUP.md            
└── assets/                     ← At root level!
    ├── icon.png
    ├── splash.png
    ├── adaptive-icon.png
    └── favicon.png

✓ CORRECT - All files at root
✗ WRONG - Files inside pockettrack-mobile/ folder


STEP 5: Rebuild and Test
────────────────────────────────────────────────────────────────────────
Now rebuild your app with EAS:

  1. On your computer, open Terminal
  2. Navigate to where you cloned your GitHub repo
  3. Run: git pull
  4. Run: eas build --platform ios
  5. Wait ~10-20 minutes for build
  6. Install new build from TestFlight
  7. Open app - you should see PocketTrack!
