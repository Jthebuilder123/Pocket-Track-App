Build and wire a passwordless magic-link login and email storage system into my existing Node.js/Express + React project without breaking current routes or Plaid code. Backend: add dependencies express, cookie-parser, helmet, cors, express-rate-limit, jsonwebtoken, nodemailer, uuid, prisma and @prisma/client (use Prisma with SQLite stored at ./prisma/dev.db). Initialize Prisma and create two models: User with id, email unique, name optional, plan default “free”, createdAt, updatedAt; and EmailSignup with id, email, tag default “waitlist”, createdAt. Run migrations. Add environment variables APP_BASE_URL (my public URL), JWT_SECRET, SENDGRID_API_KEY (optional; if missing just log the magic link), FROM_EMAIL default noreply@pockettrack.app. Middleware: enable helmet, CORS with credentials for APP_BASE_URL, cookieParser, JSON body parsing, and rate limit all /api/auth/* endpoints to 10 requests per minute per IP. Routes under /api: POST /api/auth/login accepts email and optional next, lowercases the email, stores it in EmailSignup with tag “app_login”, creates a JWT containing the email that expires in 15 minutes, builds a magic link to GET /api/auth/magic with token and next, and sends it by email via Nodemailer using SendGrid if SENDGRID_API_KEY is set, otherwise logs the link to the server; returns ok true. GET /api/auth/magic verifies the JWT, upserts User by email, sets a secure httpOnly cookie named session containing a signed JWT valid for 14 days, then redirects to next or root; handle expired or invalid token by redirecting to /login with an error query. POST /api/auth/logout clears the session cookie and returns ok true. POST /api/signup accepts email and inserts it into EmailSignup with tag “waitlist” and returns ok true. GET /api/me reads the session cookie, verifies it, and returns email and plan when authenticated, or 401 when not. Expose GET /healthz that returns JSON with status ok and booleans env_ok and db_ok. Frontend React: add a Login page at /login with an email field and submit button that posts to /api/auth/login with next set to /dashboard, shows “Check your email for a sign-in link” on success, and handles error states. On app load, call /api/me to hydrate auth state; protect dashboard and other private routes by redirecting unauthenticated users to /login; add a Logout button that calls POST /api/auth/logout and returns to /login. Add a simple waitlist form that posts email to /api/signup. Security and UX: never expose JWT_SECRET to the client, normalize emails to lowercase, set cookies httpOnly and sameSite=lax and secure in production https, handle rate-limit errors with a friendly message, and keep all new code modular and documented. Deliverables: updated package.json with new dependencies, Prisma setup and migration, new Express auth and signup routes with middleware and rate limits, React login page and route protection, waitlist capture, and README notes explaining env variables and how to test magic links when SENDGRID_API_KEY is absent.
